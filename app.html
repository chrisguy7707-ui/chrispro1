      치수 허용오차 ±1cm (별도 협의 시 협의값 우선)
      베타 · 이 패턴은 표준 공식으로 계산한 참고용이며, 실제 재단·봉제로 검증되지 않았습니다. 본 원단을 자르기 전에 꼭 가봉하세요.
      1. 배율 100%로 인쇄하고 첫 장의 50mm 확인 네모를 자로 재기
      2. 값싼 광목(무명)으로 재단해 시침질·가봉하기
      3. 완성품을 작업지시서 치수표와 같은 방법으로 실측 (허용 ±1cm)
      4. 앞뒤 옆선·진동둘레와 소매산·허리밴드 길이가 서로 맞는지 확인
      5. 다른 점은 이 탭의 치수 칸을 고치고, 결과를 문의 게시판에 알려 주시면 공식을 고칩니다

      읽는 법

      제도 값은 표준 공식에 따른 참고값입니다. 가봉(시착)으로 확인한 뒤 수정하세요. 인쇄물의 50mm 확인 네모로 배율을 꼭 확인하세요.

      시험 기능 · 사진에서 옷의 외곽선을 따서 모양을 판단하고, 기준 길이를 알려 주면 대략의 치수(±2~3cm)를 잽니다. AI 없이 기기 안에서 계산합니다.
      1. 옷을 바닥에 평평하게 펴고, 옷과 다른 색의 단색 배경(바닥·천) 위에서 바로 위에서 찍으세요

      3. 사람이 입은 사진·마네킹·옷걸이·복잡한 배경은 잘 안 됩니다

      항목잰 값치수표

      Gemini API 키 무료로 받기 약 3분

      키가 없어도 기기 안 인식으로 품목·디테일·컬러는 고를 수 있습니다. Gemini 키를 연결하면 사진을 보고 원단·혼용률·중량 추정, 부자재, 봉제 사양 문장까지 채워 줍니다.

      1. Google AI Studio 열기 — aistudio.google.com/app/apikey 에 접속해 구글 계정으로 로그인합니다.
      2. 약관 동의 — 처음 쓰는 계정이면 이용약관에 동의하면 기본 프로젝트와 API 키가 자동으로 만들어집니다. 키가 안 보이면 Create API key (API 키 만들기)를 누르세요.
      3. 키 복사 — 키 옆의 복사 버튼을 누릅니다. 새 키는 AQ.로, 예전 키는 AIza로 시작하는 긴 글자입니다 (둘 다 쓸 수 있음).
      4. 아래 칸에 붙여넣고 '키 확인' — 확인되면 이 브라우저에 저장되고, 3단계 버튼이 Gemini 분석으로 바뀝니다.

      꼭 알아 두세요

      • 키는 비밀번호처럼 — 다른 사람에게 보내거나 게시판·단톡방에 올리지 마세요. 이 사이트는 키를 서버에 저장하지 않고 이 브라우저에만 저장합니다.
      • 키를 Gemini 전용으로 제한 — AI Studio의 API 키 목록에서 키를 'Gemini API만 사용'으로 제한해 두면 유출돼도 피해가 줄어듭니다.
      • 무료 등급의 데이터 — Google은 무료 등급으로 보낸 내용을 제품 개선에 쓸 수 있다고 안내합니다. 아직 공개 전인 디자인이 걱정되면 키 없이 기기 안 인식만 쓰거나 유료 등급을 쓰세요.
      • 사용 한도 — 무료 등급은 분당·하루 요청 수 제한이 있습니다. '요청이 많습니다'가 뜨면 잠시 후 다시 누르세요.
      • 새 AQ. 키가 거부될 때 — 2026년부터 AI Studio는 AQ.로 시작하는 인증 키만 발급합니다. 일부 계정에서는 Google 쪽 문제로 이 키가 거부(401)되는 사례가 보고되어 있습니다. 새 프로젝트에서 다시 발급해 보고, 그래도 안 되면 키 없이 기기 안 인식을 쓰세요.
      • 공식 안내: Gemini API 키 사용법 · 무료 등급과 요금
