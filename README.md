# 작업지시서 메이커

옷 사진을 올리고 사이즈(남 80~110, 여 44~88)를 고르면 한국형 작업지시서를 만들어 줍니다.

## 사용 순서
1. 옷 사진 올리기 (정면 1장)
2. 성별·출력 사이즈 선택 (노란 테두리 = 기준 샘플 사이즈, 더블클릭으로 변경)
3. "사진으로 도식화·작업지시서 만들기" → AI가 품목·디테일·소재·봉제 사양 추정
4. 디테일 확인·수정 → 오른쪽 작업지시서의 글자는 직접 눌러 수정
5. 인쇄·PDF 저장 / 작업지시서 파일(HTML) 저장 / 도식화 SVG 저장

## AI 분석
- claude.ai에서 열면 Claude가 분석합니다 (키 불필요, 처음 한 번 사용 허락).
- 직접 호스팅하면 Gemini API 키를 입력해 사용합니다 (aistudio.google.com 무료 발급, 이 브라우저에만 저장).
- 키가 없어도 4단계에서 직접 선택하면 작업지시서를 만들 수 있습니다.

## 주의
- 치수표는 레귤러핏 참고 표준값입니다. 반드시 샘플 실측으로 수정하세요.
- 자체 디자인·자체 샘플에 사용하세요. 타인 제품 형태를 모방하는 용도는 법적 문제가 될 수 있습니다.
