# 작지 — 옷 작업지시서 메이커

옷 사진을 올리고 사이즈(남 80~110, 여 44~88)를 고르면 도식화·치수표·원단·봉제 사양이 담긴 한국형 작업지시서를 A4 한 장으로 만들어 줍니다.

## 페이지
| 파일 | 내용 |
|---|---|
| `index.html` | 대문: 사이트 소개, 사용 순서, 기능, 자주 묻는 질문 |
| `app.html` | 작업지시서 만들기 도구 |
| `guide.html` | 작업지시서 작성법 (도식화·치수 재는 법·봉제 용어) |
| `learn.html` · `learn-*.html` | 배우기: 원단, 요척·원가, 샘플 과정, 사이즈·핏, 케어라벨, 샘플 검수, 도식화, 봉제 용어 사전, 소재별 세탁 안내서 9편 |
| `factory.html` | 공장 찾기 안내 (준비물·공공 지원·연결 서비스·공장에 물어볼 질문) |
| `about.html` · `contact.html` | 사이트 소개 · 문의 |
| `privacy.html` · `terms.html` | 개인정보처리방침 · 이용약관 (애드센스 쿠키 고지 포함) |
| `en/` | 영어판 6쪽 (대문·작성법·소개·문의·개인정보처리방침·이용약관). 도구는 `app.html?lang=en`으로 영어 화면 (번역 사전 `assets/i18n-en.js`). 작업지시서 언어는 화면과 따로 한국어·English·한·영 병기 선택 |

## 도구 사용 순서
왼쪽 패널은 **① 사이즈 → ② 디테일** 두 단계입니다. 사진은 필수가 아닙니다.
1. 성별·출력 사이즈 선택 (노란 테두리 = 기준 샘플 사이즈, 더블클릭으로 변경)
2. 디테일 확인·수정: **대분류 → 소분류(34종)**·핏·넥라인·여밈·주머니·원단·컬러·품명, 상의 소매 종류(일반·드롭숄더·래글런)·밑단 모양, 바지 허리(고정·고무줄)·앞뒤 주머니 모양·카고·앞 주름. AI 없이 여기서 직접 골라도 됩니다. 파우치는 S·M·L 사이즈.
   - 도식화는 치수표 기준 사이즈 비율대로 그려지고, 치수를 고치면 함께 바뀝니다. Claude 분석(claude.ai 안)은 사진 비율을 '제안'으로 보여 주고, 눌러야 치수표에 반영합니다.
3. **도식화 편집 탭**: 앞판 빨간 손잡이를 끌면 치수표 기준 사이즈 값이 바뀌고 도식화도 따라 바뀜. 주머니 같은 디테일은 직접 끌어 옮김(좌우 한 쌍은 대칭, '디테일 위치 처음으로'). 메모·화살표·동그라미(파란색), 선택 지우기·되돌리기. 표시는 작업지시서·인쇄·저장에 포함
4. **생산 준비 탭**: ① 빠진 항목 검사(공장이 다시 물어볼 질문, 누르면 그 칸으로) ② 원가·마진 계산기(요척×단가×로스 + 부자재·공임·기타 + 샘플비÷수량) ③ 컬러×사이즈 발주표 → 작업지시서 수량·컬러에 넣기, 엑셀(CSV, BOM) 내보내기 ④ 케어라벨 법정 표시 7항목 문구(가정용 섬유제품 안전기준), 부자재표에 넣기 ⑤ 샘플 실측 기록(±1cm 넘으면 빨강, 차수 저장·비교) ⑥ 공장 찾기 안내(factory.html)
5. 인쇄·PDF 저장 / HTML로 내보내기 / 도식화 SVG 저장
   - **작업 저장·열기(.json)**: 작업지시서·치수 수정·사진·패턴 입력을 파일로 저장했다가 다시 열기. 이 브라우저에는 자동 저장되어 다음에 '이어서 하기'
7. **사진 분석 탭 (시험)**: 옷 사진 올리기와 사진 자동 인식(브라우저 안에서 무료로 품목·디테일·컬러, 처음 한 번 모델 약 23MB, 상위 후보 3개)이 여기 있습니다. claude.ai 안에서 열면 Claude가 소재·봉제 사양까지 분석합니다. (Google Gemini 분석은 2026-10-07에 뺐습니다.) 아래는 외곽선 분석: 펼친 옷 사진에서 외곽선을 따 모양을 참고로 판단하고, 사진 속 기준선(A4·자)으로 cm를 환산해 고른 치수를 작업지시서 기준 사이즈에 넣음. 외곽선 SVG 저장. AI 없음
6. **패턴 제도 탭 (베타)**: 작업지시서 소분류 34종 전체(파우치 포함, 치수표 기준 사이즈 값으로 자동 제도 · 카라티 칼라·카디건 앞단·후드 집업·셔츠 원피스 여밈·청바지 요크·조거·카고·플리츠·머메이드·랩 스커트 모양 반영) + H라인 스커트(신체 치수)·사각 지퍼 파우치. 제도도·계산표, 인쇄하면 축소도 1장 + 실물 크기 A4 분할(배율 100%, 50mm 확인 네모) 또는 대형 한 장, 실물 크기 SVG 저장

## 개발
```bash
npm install          # 검사·이미지 생성용 (puppeteer-core, 설치된 Chrome 사용)
npm run serve        # http://localhost:8766
npm test             # 도구 67개 + 사이트 22개 항목 검사 (인식 모델 다운로드에 인터넷 필요)
npm run configure    # site.config.json → 모든 페이지 <head>, sitemap.xml, robots.txt, ads.txt
npm run images       # 대문 미리보기·공유 이미지 다시 만들기
npm run clip-labels  # 사진 인식 후보 문장을 바꿨을 때 assets/clip-labels.json 다시 만들기
```

공개 사이트 검사 (배포 후):
```bash
APP_URL=https://jakji.app/app.html node tests/verify.mjs
SITE_URL=https://jakji.app/ node tests/site.mjs
```
GitHub CDN은 자동화 브라우저에만 봇 탐지 스크립트를 끼워 넣기 때문에, 공개 사이트 검사에서는 그 요청을 막고 일반 방문자 기준으로 확인합니다.

## 공개하고 애드센스 신청하기

### 1. 사이트 주소 정하기
- **GitHub Pages:** 저장소 Settings → Pages → Branch `main` / `/ (root)` 저장. 주소는 `https://chrisguy7707-ui.github.io/chrispro1/`.
- **애드센스는 직접 소유한 도메인이 필요합니다.** `github.io`의 하위 폴더 주소로는 사이트 추가와 `ads.txt` 확인이 되지 않습니다. 도메인(예: `.com`, `.kr`)을 사서 GitHub Pages의 Custom domain에 연결하세요.
- 주소가 정해지면 `site.config.json`의 `url`을 바꾸고 `npm run configure`를 실행합니다.

### 2. 검색 등록 (SEO)
- [Google Search Console](https://search.google.com/search-console)에 사이트 추가 → HTML 태그 방식의 `content` 값을 `googleSiteVerification`에 넣고 `npm run configure` → 배포 → 확인 → `sitemap.xml` 제출
- [네이버 서치어드바이저](https://searchadvisor.naver.com/)도 같은 방식으로 `naverSiteVerification`에 넣고 사이트맵을 제출합니다.

### 3. 애드센스 승인 신청
1. [Google 애드센스](https://adsense.google.com/) 가입 → 사이트 추가 → 게시자 ID(`ca-pub-숫자16자리`) 확인
2. `site.config.json`의 `adsenseClient`에 게시자 ID를 넣고, `contactEmail`에 문의 이메일을 넣습니다.
3. `npm run configure` → 커밋·푸시. 모든 페이지 `<head>`에 애드센스 코드와 `google-adsense-account` 메타 태그가 들어가고, 루트에 `ads.txt`가 생깁니다.
4. 애드센스 화면에서 사이트 연결 확인 → **검토 요청**. 보통 며칠~몇 주 걸립니다.

### 4. 승인 후 광고 넣기
- **자동 광고:** 애드센스 화면에서 켜기만 하면 됩니다(코드는 이미 들어가 있음).
- **정해진 자리:** 광고 단위를 만들고 ID를 `adSlots`에 넣은 뒤 `npm run configure`. 자리는 `home-mid`(대문 중간), `home-bottom`(대문 FAQ 아래), `guide-mid`(작성법 중간), `factory-mid`(공장 찾기 중간)입니다. **도구 화면(app.html)에는 광고 칸을 두지 않습니다**(작업 화면·버튼 옆 광고는 실수 클릭으로 보일 수 있어 정책 위험). ID가 없는 자리는 화면에 나타나지 않고, 작업지시서 인쇄물에는 광고가 나오지 않습니다.
